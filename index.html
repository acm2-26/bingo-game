📖 Game Explanation & Rules

🎯 Winning Patterns Explained

To declare BINGO, players must complete the current active pattern on their 5x5 grid:

Standard Line
Any 5 in a row (Row, Col, or Diagonal)
Four Corners
Only the 4 outer corner spaces
X-Shape
Both diagonals crossing the middle
Full House
Every single space covered

🕹️ How the Game Modes Work

  • Host Mode: Generates a live QR code for mobile players to scan. Displays the master 1–75 caller grid, speech voice caller, winner logs, and session saving.
  • Mobile Sync Play: Scanning the Host QR code links a mobile device directly without downloading any app. Winning triggers an instant alert to the Host.
  • Print Advance Cards: Allows background batch generation of up to 1,000 unique printable paper cards for offline venues.
